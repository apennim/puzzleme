## 本週小結（第 7 週）

這週的重點是「社群」與「好友一起出遊」：

1. **個人主頁與貼文**：登入後先建立個人資料，個人主頁會列出自己發過的貼文，並可以編輯、刪除。
2. **照片體驗**：首頁改成一欄下滑、照片統一 4:5，發文時可以自己裁切照片，點進貼文看得到完整照片。
3. **好友行程邀請**：從收藏的景點發起行程、邀請好友，好友按 Join! 加入；畫面依 Figma 設計稿製作，並依手機實測回饋調整了三輪。
4. **行程設定**：發起人可以決定行程公開範圍、人數上限、景點數上限，以及成員能不能新增下一個景點（資料庫端用 trigger 強制上限）。

## 本週 AI 協助紀錄

> 依專題規範，記錄從 AI（Claude Code）獲得的關鍵協助。畫面設計由本人提供 Figma 稿，並在手機實測後回饋修改。

| 項目 | AI 協助內容 | 我學到的概念 |
|---|---|---|
| 照片裁切 | 不另外安裝套件，用 canvas 實作拖曳＋縮放裁切 | 把畫面上的裁切框換算回原圖座標，再用 `drawImage` 輸出 |
| 編輯／刪除貼文 | 撰寫 Supabase RLS 規則，只允許作者本人修改 | 權限要在資料庫端擋，前端隱藏按鈕不等於安全 |
| 行程邀請權限 | 用 security definer 函式避免兩張表的 RLS 互相參照造成無限遞迴 | RLS 遞迴問題與解法 |
| 人數／景點上限 | 用資料庫 trigger 在寫入前檢查數量 | trigger 會在每筆資料寫入前自動執行，可以強制商業規則 |
